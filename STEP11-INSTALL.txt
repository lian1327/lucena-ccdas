CCADSS - STEP 11: EXECUTIVE DECISION SUPPORT (Mayor / City Administrator)
=========================================================================

What it adds (sidebar: Executive; City Admin and Mayor only)
  * Monthly picture, any month (default: last complete month). Counts PROBLEMS: reports of the same problem are merged;
    "Mga nag-report" shows how many people reported.
  * Barangay x issue heatmap: click a column to rank barangays by that issue (most garbage, traffic, drainage...).
    Includes per-1,000 residents, open and overdue now. CSV export for Excel.
  * Top 5 barangays per issue.
  * Insights (Module 8), in Filipino or English, generated with minimum-count rules so small numbers don't raise alarms:
      city-wide and per-issue changes (e.g. "Drainage complaints decreased by 37% city-wide (46 -> 29)"),
      barangay spikes ("Road damage complaints increased by 60% in Barangay X (5 -> 8)"),
      one barangay producing >=25% of an issue, barangays in the top 3 for an issue 3 months running,
      offices short on capacity
  * Next-month forecast per issue with an 80% range. For each issue, 4 simple methods are back-tested on the last
    4 months and the most accurate is used; the error is shown next to a "same as last month" guess.
  * Resource recommendations per office: capacity (resolved/month) vs expected cases + backlog/3, shortfall,
    extra field staff needed, barangays to focus on. Planning estimates, not orders.
  * Printable Monthly Report for the Mayor (A4, Filipino or English), with signature lines.
  * PACD triage: "Posibleng kapareho" on each open case (same barangay, last 14 days, similar wording/type/location)
    with a one-click I-link. This catches same-problem reports that auto-linking missed (no pin / different category).

Install (extract into lucena-ccdas, overwrite) - no new database tables
  cd backend ; .\.venv\Scripts\Activate.ps1 ; python manage.py runserver
  cd frontend ; npm run gen:api ; npm run dev
  Log in as cityadmin or mayor -> Executive

Notes
  * Barangay populations in the demo are placeholders. Load PSA 2020 census figures in Django admin -> Barangays
    so "per 1,000 residents" is real.
  * With only 12 months of data the forecast can't learn the rainy season yet; seasonality switches on
    automatically once there are 24 months of data. Say so at the defense.
